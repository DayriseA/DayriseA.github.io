About Me

I'm an application developer based in Toulouse. Over the past year, I've been freelancing, building full-stack web applications with a soft spot for the backend. Before that, I spent seven years in product data and IT roles, which taught me to care about clean data and tools that actually work for the people using them.

Curiosity got me testing AI early, but the hype outran the results, so I stayed a skeptic who kept trying each new release. Once it became genuinely capable, I went all in. Today I work hand in hand with AI coding agents, deliberately and responsibly: AI is a tool I steer, not an autopilot.

I'm now looking for a full-time role where I can keep growing alongside an experienced team.
